# (thresh)Hold The Line

## Advances in VTSearch Calibration
### Sam Greenberg

<!-- Open by saying what the room is in for, because half the talk is a tool
     most of them have never used and the other half is a statistics problem
     inside it.

     VTSearch lets someone search a pile of unlabeled media for a concept they
     can describe but cannot query for. They vote Good or Bad on one item at a
     time; a small model learns from those votes and ranks everything else.
     Somewhere in that ranking a line has to be drawn — above it is a match,
     below it is not. This talk is about that one line: where it goes, why it
     is hard to place, and five attempts to place it better.

     Two promises up front. First, the deck spends its opening third on what
     the tool is, because the interesting thing about the line is that it does
     two jobs, and the second job only makes sense once the loop is on the
     table. Second, every number in the deck comes from a committed
     experiment report — nothing is from memory — and the arc ends on a
     negative result, on purpose. -->
