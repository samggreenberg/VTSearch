# Tutorials

End-to-end worked examples that go deeper than the
[quickstart](../quickstart.md). Each tutorial picks one realistic
scenario and walks through the relevant `vtscore` packages in order.

| Tutorial | Scenario | Length |
|----------|----------|--------|
| [Train and score a detector end-to-end](train-and-score.md) | Build a "dog barks" audio detector from scratch, evaluate it, persist it, reload it in a fresh process | ~30 min |

More tutorials may land here over time. If you've written something
useful with `vtscore` and want to contribute it, open a PR - tutorials
are deliberately use-case-driven, not exhaustive.
