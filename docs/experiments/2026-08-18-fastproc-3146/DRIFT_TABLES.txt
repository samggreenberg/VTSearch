=== 2. Drift relative to the reproduction floor ===
The floor arm is the SAME code on the SAME node, run twice, so its drift is
pipeline nondeterminism and nothing else.  A treatment number without this
denominator is unreadable: 1e-3 means one thing against a floor of 0 and
another against a floor of 1e-4.
