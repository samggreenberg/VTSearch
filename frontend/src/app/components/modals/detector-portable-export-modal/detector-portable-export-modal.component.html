⚠ This writes a trained detector to disk.

VTSearch normally keeps trained detectors in memory only — this export is the deliberate exception. The bundle contains no raw media and no fingerprints: just the small trained detector, the name of the embedder to use, and the cutoff. (A trained detector can still reveal some information about its training data, so share it only with parties you'd trust with the labels themselves.)

What You'll Get

  • detector.onnx — the trained detector (runs anywhere).
  • manifest.json — the embedder to use and the cutoff.
  • README.md — which embedder to use and a copy-paste scoring snippet.

The detector is trained against the currently loaded dataset's embedder, so a compatible dataset must be loaded.
