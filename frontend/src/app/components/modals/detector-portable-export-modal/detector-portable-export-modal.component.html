⚠ This writes a trained model to disk.

VTSearch normally keeps trained models in memory only — this export is the deliberate exception. The bundle contains no raw media and no embeddings: just the small trained classifier, the name of the embedder to use, and the threshold. (A trained model can still reveal some information about its training data, so share it only with parties you'd trust with the labels themselves.)

What you'll get

  • detector.onnx — the trained scorer (runs anywhere via onnxruntime).
  • manifest.json — the embedder, embedding size, and threshold.
  • README.md — which embedder to use and a copy-paste scoring snippet.

The model is trained against the currently loaded dataset's embedder, so a compatible dataset must be loaded.
